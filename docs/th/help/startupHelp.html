การทดสอบอิชิฮาระเป็นการทดสอบการมองเห็นสีเพื่อตรวจหาความบกพร่องในการมองเห็นสีแดง-เขียว ประกอบด้วยแผ่นภาพอิชิฮาระหลายแผ่น ซึ่งเป็นแผ่นภาพแบบเสมือนสีเดียวกัน

แอปพลิเคชันนี้มีชุดภาพอิชิฮาระและภาพที่ได้รับแรงบันดาลใจจากอิชิฮาระหลายชุด ซึ่งสามารถนำเสนอได้ทั้งแบบเรียงลำดับหรือแบบสุ่ม สำหรับแต่ละภาพ ผู้ทดสอบจะพยายามระบุตัวเลขหรือรูปแบบ (เช่น เส้น) ที่ซ่อนอยู่ภายในภาพ การตอบสนองจะถูกบันทึกโดยการเลือกปุ่มที่เหมาะสมจากกลุ่มตัวเลือก ซึ่งหนึ่งในนั้นจะตรงกับรูปทรงที่มองเห็นได้

ก่อนที่คุณจะเริ่มต้น

  • ปิดโหมด Night Shift / True Tone / โหมดถนอมสายตา
  • ปิดใช้งานโหมดการแสดงผลสีสดใส / ปรับได้ / ปรับปรุงแล้ว
  • ตั้งค่าความสว่างเป็น 70% หรือสูงกว่า
  • ใช้แสงสีขาวที่เป็นกลาง (หลีกเลี่ยงแสงโทนสีเหลือง)
  • หลีกเลี่ยงแสงแดดโดยตรงหรือแสงสะท้อนจากหน้าจอ
  • ถืออุปกรณ์ให้ห่างประมาณ 30-40 เซนติเมตร และมองตรงๆ
