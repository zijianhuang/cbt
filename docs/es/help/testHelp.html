La sesión de prueba comienza con la primera lámina de Ishihara y continúa hasta que se completa la última lámina.

Para cada lámina de Ishihara, el sujeto de prueba selecciona el botón correspondiente entre las opciones disponibles. Una vez seleccionada una respuesta, la aplicación muestra la siguiente lámina.

Al finalizar la sesión de prueba, la aplicación muestra los resultados de la prueba.
