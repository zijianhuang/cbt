El test de Ishihara es una prueba de visión cromática para la detección de deficiencias en la visión del rojo y el verde. Consiste en una serie de láminas de Ishihara, que son un tipo de lámina seudoisocromática.

Esta aplicación ofrece varios conjuntos de láminas de Ishihara y otras inspiradas en ellas, las cuales pueden presentarse de forma secuencial o aleatoria. Ante cada lámina, la persona evaluada intenta identificar el número o patrón (como una línea) oculto en la imagen. Las respuestas se registran seleccionando el botón correspondiente de entre un grupo de opciones, una de las cuales se corresponde con la figura percibida.

Antes de empezar

  • Desactivar Night Shift / True Tone / Modo de confort visual
  • Desactiva los modos de pantalla Vívido, Adaptativo o de color mejorado.
  • Ajusta el brillo al 70 % o más.
  • Utilice iluminación blanca neutra (evite la iluminación cálida o amarillenta).
  • Evite la luz solar directa o el resplandor en la pantalla.
  • Sostenga el dispositivo a unos 30–40 cm de distancia y mírelo de frente.
