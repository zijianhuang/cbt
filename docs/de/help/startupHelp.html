Der Ishihara-Test ist ein Farbsehtest zur Erkennung von Rot-Grün-Sehschwächen. Er besteht aus einer Reihe von Ishihara-Tafeln, die eine Art pseudoisochromatischer Tafeln darstellen.

Diese App bietet mehrere Sets von Ishihara- und Ishihara-inspirierten Tafeln, die entweder nacheinander oder in zufälliger Reihenfolge präsentiert werden können. Bei jeder Tafel versucht die Testperson, die im Bild verborgene Zahl oder das Muster (z. B. eine Linie) zu erkennen. Die Antworten werden durch Auswahl der entsprechenden Schaltfläche aus einer Gruppe von Optionen aufgezeichnet, wobei eine der erkannten Figur entspricht.

Bevor Sie beginnen

  • Nachtmodus / True Tone / Augenkomfortmodus deaktivieren
  • Deaktivieren Sie die Farbdarstellungsmodi „Lebhaft“, „Adaptiv“ und „Erweitert“.
  • Stellen Sie die Helligkeit auf 70 % oder höher ein.
  • Verwenden Sie neutralweißes Licht (vermeiden Sie warmes/gelbes Licht).
  • Vermeiden Sie direkte Sonneneinstrahlung oder Bildschirmblendung.
  • Halten Sie das Gerät in einem Abstand von ca. 30–40 cm und schauen Sie es frontal an.
