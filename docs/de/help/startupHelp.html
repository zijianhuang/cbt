Der Ishihara-Test ist ein Farbsehtest zur Erkennung von Rot-Grün-Sehstörungen. Er besteht aus einer Reihe von Ishihara-Tafeln, bei denen es sich um eine Art pseudoisochromatischer Tafeln handelt.

Diese App bietet verschiedene Sätze von Ishihara- und Ishihara-ähnlichen Tafeln, die entweder nacheinander oder in zufälliger Reihenfolge angezeigt werden können. Bei jeder Tafel versucht die Testperson, die im Bild verborgene Zahl oder das Muster (z. B. eine Linie) zu erkennen. Die Antworten werden erfasst, indem die entsprechende Schaltfläche aus einer Auswahl von Optionen gewählt wird, von denen eine der wahrgenommenen Figur entspricht.

Bevor Sie beginnen

  • Night Shift / True Tone / Augenkomfort-Modus ausschalten
  • Deaktivieren Sie die Farbmodi „Lebhaft“, „Adaptiv“ oder „Verbessert“.
  • Stellen Sie die Helligkeit auf 70 % oder höher ein.
  • Verwenden Sie neutralweißes Licht (vermeiden Sie warmes/gelbes Licht).
  • Vermeiden Sie direktes Sonnenlicht oder Blendungen auf dem Bildschirm.
  • Halten Sie das Gerät in einem Abstand von ca. 30–40 cm und betrachten Sie es frontal.
