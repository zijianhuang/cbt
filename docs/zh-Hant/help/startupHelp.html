石原氏測驗（Ishihara test）是一種用於檢測紅綠色覺缺陷的色覺檢查。它由一系列石原氏圖譜組成，這類圖譜屬於假同色圖（pseudoisochromatic plate）。

本應用程式提供多組石原氏（Ishihara）色盲檢測圖及仿石原氏風格的圖卡，這些圖卡可按順序或隨機順序顯示。針對每一張圖卡，受試者需嘗試辨識隱藏於圖像中的數字或圖案（例如線條）。受試者透過從一組選項中選取對應按鈕來記錄結果，其中一個選項即對應其所辨識出的圖形。

開始之前

  • 關閉 Night Shift / True Tone / 護眼模式
  • 停用鮮豔、自適應或增強色彩顯示模式
  • 將亮度設定為 70% 或更高
  • 使用中性白光照明（避免使用暖光或黃光）。
  • 避免陽光直射或螢幕眩光
  • 將裝置保持在約 30–40 公分的距離，並正對觀看。
