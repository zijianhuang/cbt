Тестовая сессия начинается с первой пластины Исихары и продолжается до завершения последней пластины.

Для каждой пластины Исихары испытуемый выбирает соответствующую кнопку из доступных вариантов. После выбора ответа приложение отображает следующую пластину.

В конце тестовой сессии приложение отображает результаты тестирования.
