Сеанс тестирования начинается с первой таблицы Ишихары и продолжается до тех пор, пока не будет пройдена последняя таблица.

Для каждой таблицы Ишихары испытуемый выбирает соответствующую кнопку из предложенных вариантов. После выбора ответа приложение показывает следующую таблицу.

По завершении сеанса тестирования приложение отображает результаты теста.
