Тест Ишихары — это тест на цветовое зрение для выявления красно-зеленой цветовой недостаточности. Он состоит из серии таблиц Ишихары, которые представляют собой разновидность псевдоизохроматических таблиц.

Это приложение предоставляет несколько наборов изображений Исихары и изображений, созданных по мотивам этой головоломки, которые могут отображаться как последовательно, так и в случайном порядке. Для каждого изображения испытуемый пытается определить число или узор (например, линию), спрятанный внутри изображения. Ответы записываются путем выбора соответствующей кнопки из группы вариантов, один из которых соответствует воспринимаемой фигуре.

Прежде чем начать

  • Отключите режимы «Ночной режим» / «Настоящий тон» / «Защита глаз».
  • Отключить режимы отображения «Яркий» / «Адаптивный» / «Улучшенный цвет».
  • Установите яркость на 70% или выше.
  • Используйте нейтральное белое освещение (избегайте теплого/желтого освещения).
  • Избегайте прямых солнечных лучей и бликов на экране.
  • Держите устройство на расстоянии примерно 30–40 см и смотрите прямо перед собой.
