Uma sessão de teste começa com a primeira prancha de Ishihara e prossegue até que a última prancha seja concluída.

Para cada prancha de Ishihara, o participante seleciona o botão correspondente entre as opções disponíveis. Após a seleção de uma resposta, o aplicativo apresenta a próxima prancha.

Ao final da sessão de teste, o aplicativo exibe os resultados do teste.
